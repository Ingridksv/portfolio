## 4. semester – Systemudvikling og valgfag

På 4. semester har jeg arbejdet med systemudvikling i et større agilt projekt samt to valgfag: Game Development og AI-Driven Applications.

### Systemudvikling

I systemudvikling arbejdede vi med et større projekt i et Scrum of Scrums-setup, hvor flere teams samarbejdede om videreudvikling af et eksisterende system.

**Emner og metoder:**

* Scrum og agile arbejdsprocesser
* Sprint planning, daily scrum, sprint review og retrospective
* Product backlog og backlog refinement
* User stories og acceptance criteria
* Definition of Done
* GitHub, branches og pull requests
* Analyse, dokumentation og videreudvikling af eksisterende kode
* Rollebaseret adgang og backend-logik

**Projekt:** CareBridge 2.0
Mit fokus var især backend, analyse, adgangsstyring, roller/rettigheder og dokumentation af udviklingsprocessen.

### Valgfag: Game Development

I valgfaget Game Development har jeg arbejdet med spiludvikling og grundlæggende game design. Forløbet gav mig erfaring med, hvordan man udvikler interaktive applikationer med fokus på spilmekanikker, brugerinput og objektorienteret programmering.

**Teknologier og værktøjer:**

* Unity
* Unity Hub
* C#
* GameObjects og Components
* Scenes
* Scripts
* Input og interaktion
* Game loop og spilmekanikker

**Kompetencer:**

* Opsætning og strukturering af Unity-projekter
* Arbejde med scripts og komponentbaseret udvikling
* Forståelse for spilmekanikker og interaktive systemer
* Anvendelse af objektorienteret programmering i en spil-kontekst

### Valgfag: AIDA – AI-Driven Applications

I valgfaget AI-Driven Applications arbejdede jeg med AI-baserede applikationer, chatbots og praktisk brug af large language models.

**Emner og teknologier:**

* Chatbots
* RAG-løsninger
* Prompt engineering
* LLM API’er
* Dify
* Embeddings
* Semantic search
* AI-understøttede applikationer
* Teknisk formidling via portfolio og blogindlæg

**Kompetencer:**

* Forståelse for hvordan AI kan integreres i applikationer
* Arbejde med RAG og chatbot-løsninger
* Brug af LLM’er gennem API’er
* Formidling af tekniske AI-løsninger på en forståelig måde
